# CC Switch v3.21.0

> This release centers on the terminal workbench and provider-switching reliability. The embedded terminal learns alternate-scroll — while a full-screen TUI such as opencode owns the alternate buffer, wheel events are translated into arrow keys, so the wheel finally scrolls; the bottom prompt follows the selected terminal tab instead of writing into the previous session's PTY; the three-column layout's right-hand model list becomes collapsible (a narrow strip with a vertical label, persisted across restarts) and loses its redundant title; and the terminal header stats chip finally names the model it is measuring. Provider switching gets two reliability fixes: the card's primary click switches again (the usage-pin rewrite had left only the context menu, read under proxy takeover as "switching has no effect"), and context-menu clicks no longer bubble into an accidental switch that made the clicked provider current — which then blocked its deletion as "current provider cannot be deleted". A stale `live_backup` row surviving a crash no longer pins every switch to a dead proxy's hot-switch path. The rate statistics write the model name they previously never stored and expire stale live bursts left by streams that ended without a usage record. New this release is a factory reset: the settings page gains a type-RESET-gated section that stops the proxy, restores every taken-over client config, snapshots the database, wipes user data and restarts automatically. **This release contains no database migration.**

## Highlights: What You Can Do Now

- **Scroll opencode with the wheel in the embedded terminal**: full-screen TUIs run in xterm's alternate buffer, which has no scrollback, and with mouse tracking off the wheel did nothing; wheel deltas are now translated into arrow-key sequences written to the PTY, matching Windows Terminal's default behavior. Normal-buffer scrolling and mouse-aware TUIs such as htop are untouched.
- **Delete a model from its context menu normally**: the menu is a DOM child of the card, so clicking 删除 also fired the card's switch handler — the clicked provider became current, which then blocked its own deletion. Menu clicks are now fully contained.
- **Left-click a provider card to switch**: the primary click again mirrors the context menu's primary action; in failover mode it toggles queue membership; OMO and additive cards keep the usage pin so a stray click cannot disable or remove them.
- **The bottom prompt always writes to the selected terminal**: input no longer lands in the previous session after a tab switch; the prompt reports unavailable until the new session connects.
- **Collapse the right-hand model list**: like the left panel, it folds into a 32px strip with a vertical label, and the state survives restarts; the header usage display stays clear of the hover-revealed button, and the redundant 模型列表 title is gone.
- **See the model name in the stats chip**: the terminal header's tok/s chip now shows the resolved model of the last request (the tooltip previously always read 未知模型), with long names truncated and speed numbers no longer jittering above 100 tok/s.
- **Factory reset in one click** (Settings → Advanced → Reset All Configuration): gated behind a type-RESET confirmation. The flow: stop the local proxy and restore every taken-over client config (Claude / Codex and friends keep working) → snapshot the database into the backups directory (recoverable later from Backup & Restore) → wipe user data inside one transaction (providers, profiles, prompts, MCP, custom endpoints, proxy takeover state, usage and session records) → reset app settings → restart automatically. Model pricing seeds and skill content are preserved.
- **Switching recovers after a crash**: a crash mid-takeover left a `live_backup` row behind, forcing every later switch into hot-switch mode that never wrote real endpoints back into the client config; when a backup exists without a live takeover placeholder and the proxy is not running, the row is cleared and the switch performs a normal write.
- **Rate numbers are no longer poisoned by aborted streams**: a stream whose usage fails to parse no longer leaves its live-burst counters dirty, so the next generation's tok/s starts fresh instead of sticking low.
- **The READMEs document the terminal workbench**: the three-column workbench (projects, terminal instances, session resume, git changes panel, live stats, HUD floating window) is now covered.
